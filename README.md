## 📌 为什么有这个指南

很多新手第一次接触"科学上网"时，面对一堆名词——**VPN、机场、专线、中转、CN2、倍率、Clash、节点**——完全是懵的。

这个指南的目标很简单：

> **让一个完全不懂的人，看完就能明白：**
> 1. 这些东西到底是什么
> 2. 自己需要哪一种
> 3. 怎么买、怎么装、怎么用
> 4. 出了问题怎么办
